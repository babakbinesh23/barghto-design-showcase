# گالری طرح‌های وب‌سایت برقتو

**A static portfolio and selection gallery for Persian solar-energy website concepts.**

این مخزن صفحه‌ای مستقل برای مقایسه طرح‌های شماره ۳ تا ۹ وب‌سایت برقتو است. هدف، انتخاب و بررسی زبان بصری، تعاملات و چیدمان طرح‌های پیشنهادی است؛ نه ارائه یک سرویس عملیاتی فروش برق.

| طرح | ایده اصلی | مخزن |
| --- | --- | --- |
| ۳ | لندینگ پویا، انیمیشن اسکرول و محاسبه‌گر | [tarh-3](https://github.com/babakbinesh23/tarh-3) |
| ۴ | شبکه خورشیدی آینده، فضای تیره و سینمایی | [tarh-4](https://github.com/babakbinesh23/tarh-4) |

## پیاده‌سازی

- صفحه گالری: `index.html`
- ساختار HTML، استایل CSS و تعاملات ساده در همان فایل
- فونت فارسی Vazirmatn از Google Fonts
- کارت‌های طرح به نشانی‌های GitHub Pages هر مخزن اشاره می‌کنند. **فعال‌بودن GitHub Pages در هر مخزن باید جداگانه بررسی شود.**

## پیش‌نمایش محلی

```bash
python -m http.server 8000
```

در مرورگر نشانی `http://localhost:8000/` را باز کنید. بدون Node.js، دیتابیس یا Build قابل مشاهده است.

## محدودیت‌ها

- این گالری خودش سورس همه طرح‌ها را در بر ندارد؛ سورس هر طرح در مخزن جداگانه آن است.
- چنانچه صفحه GitHub Pages یک طرح فعال نباشد، از لینک مخزن همان طرح استفاده کنید.
- این یک نمونه‌کار طراحی است؛ ادعای تجاری یا آمار استفاده واقعی ارائه نمی‌کند.
